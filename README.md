# hibernate-lite

[![Java](https://img.shields.io/badge/Java-17%2B-orange?logo=openjdk)](https://www.oracle.com/java/)
[![Hibernate ORM](https://img.shields.io/badge/Hibernate%20ORM-6.6-blue?logo=hibernate)](https://hibernate.org/orm/)
[![Jakarta Persistence](https://img.shields.io/badge/Jakarta%20Persistence-3.1-blue?logo=eclipse)](https://jakarta.ee/specifications/persistence/)
[![License](https://img.shields.io/github/license/pf-z/hibernate-lite)](LICENSE)

**hibernate-lite** is a lightweight Java ORM framework built on top of **Hibernate ORM** and **Jakarta Persistence**.

It provides a simple and fluent API for common database operations, including CRUD, lambda-based queries, transactions, and pagination, while keeping the underlying JPA/Hibernate functionality accessible when needed.

The project is designed to reduce boilerplate and provide a lightweight, practical ORM experience for Java applications.
